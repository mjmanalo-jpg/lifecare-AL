## Deploy to Vercel

### Step 1: Create Supabase (2 min)
```
1. Go: supabase.com
2. Sign up
3. Create project
4. Copy: Project URL from settings
```

### Step 2: Deploy (1 min)
```
1. Go: vercel.com
2. Click: Import GitHub repo
3. Select: Paulparilla/Assisted-Living
4. Set: DATABASE_URL (from Supabase)
5. Deploy!
```

### Step 3: Done! (1 min)
```
Visit: https://your-app.vercel.app
Portal LIVE! 🎉
```
