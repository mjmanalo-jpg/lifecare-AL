# 01 UI UX STRATEGY

## Design System
- **Aesthetics:** Vibrant, premium, glassmorphism UI with subtle micro-animations. No generic defaults.
- **Colors:** Tailored HSL colors, strict dark mode compatibility.
- **Typography:** Inter, Roboto, or Outfit from Google Fonts.

## Wireframing Guidelines
- **Mobile-First:** Prioritized for the Caregiver Task App and Family Portal.
- **Tablet UI:** Simplified, large-text, high-contrast UI for Residents.
- **Desktop UI:** Complex grid and charting systems for the Head Nurse and Super Admin dashboards.

## Accessibility
- WCAG 2.1 AA compliance target.
- Semantic HTML and ARIA labels.
- Voice AI integration for residents with low vision or limited mobility.

## User Flows
- Family: Feed -> Summary -> Video Call
- Caregiver: Shift Start -> Task List -> Voice Charting -> Shift End
- Resident: Schedule -> Meal Tap -> SOS / Copilot Query
